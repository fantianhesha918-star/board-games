♟ オセロ

2人対戦。CPU対戦（強さ3段階）／ 2人で対面。

目的

盤（8×8）が石で埋まった時、自分の色の石が多いほうが勝ち。打てる場所が両者ともなくなった時点でも終了します。

打ち方

  • 黒が先手。自分の石で相手の石を「縦・横・斜め」いずれかの直線ではさめる場所にだけ置けます。
  • 置くと、はさんだ相手の石がすべて自分の色にひっくり返ります。
  • 置ける場所が1つもない時は自動的にパスになります。

CPUの強さ

  • よわい：1手先だけ読みます。
  • ふつう：3手先まで読みます。
  • つよい：5手先まで読み、角やへりを重視します。

🃏 神経衰弱

CPU対戦（記憶力3段階）／ 2人で対面。カード枚数 12 / 20 / 30 枚。

目的

裏向きに並んだカードを2枚ずつめくり、ペアを多く取ったほうが勝ち。

進め方

  • 自分の番に2枚めくります。ペアなら取り札にして、もう一度めくれます。
  • ペアにならなければ2枚を裏に戻し、相手の番になります。
  • すべてのカードが取られたら終了。取った枚数で勝敗を決めます。

ペアの条件

同じ数字 かつ 同じ色（♠♣＝黒、♥♦＝赤）。例：♠5 と ♣5 はペア／♠5 と ♥5 はペアになりません。

CPUの記憶力

  • よわい：見たカードを約1/3しか覚えていません。
  • ふつう：約7割を覚えています。
  • つよい：ほぼ確実に覚えています。

🂿 ババ抜き

CPU対戦 2〜4人 ／ 2人で対面。ジョーカー1枚入りの53枚を使用。

目的

手札のペアを捨てていき、いちばん早く手札を0枚にすれば勝ち。最後までジョーカーを持っていた人が負け（ババ）。

進め方

  • 配られた時点で、手札にある同じ数字2枚はすべて自動で捨てられます。
  • 自分の番に、左隣の人の手札から1枚引きます。引いたカードで数字がそろえば捨てられます。
  • 手札が0枚になった人は「あがり」。残り1人になるまで続けます。
  • 相手の手札は選びやすいように、間隔をあけた一覧で表示されます。

シャッフル機能（ババ嵐風・設定でON/OFF）

「シャッフルあり」で始めると、ジョーカーを持っている人だけが、自分が引く前に1回だけシャッフルを仕掛けられます（各プレイヤー1ゲーム1回）。

  • サイコロは6面：➡×2 / ⬅×2 / ☠×2。
  • ➡：全員の手札が一斉に右隣へ1つずつ移動。⬅：左隣へ移動。
  • ☠：不発（何も起こりません）。
  • 移動後、各手札で新しくそろったペアは自動で捨てられます。
  • 対人戦では、順番の人が引くまでの間だけ「シャッフルする／しない」ボタンが出ます。引いた（進んだ）時点で押せなくなります。

🂷 七並べ

CPU対戦 2〜4人 ／ 2人で対面。設定：人数・パス回数（3/4/5）・ジョーカー（あり/なし）。

目的

手札をいちばん早く場に出し切れば1位。上がった順に順位がつきます。

進め方

  • 各スートの7は最初から場に置かれています。自分の番に、場に置いてあるカードの隣（±1）につながるカードを1枚出します。
  • 出せない、または出したくない時はパス。パスできる回数には上限があります（設定した回数）。
  • 盤の空マスは「♥5」のような簡易表示、カードが出たマスは実際の絵柄で表示されます。

A／K の折り返し

  • あるスートがA まで並ぶと、その先は 8 以降が置けなくなり、K → Q → J → … と反対の端から折り返して埋めていきます。
  • K まで並んだ時は逆に、6 以降が置けなくなり、A → 2 → 3 → … と折り返します。

バースト

パス回数を使い切ってさらにパスするとバースト。手札を全部その位置で場に開き、そのゲームは最下位側の扱いになります（開かれたカードは他の人がつなげられます）。

ジョーカー（あり の時）

  • 自分の番に、盤の好きな空きマス（置ける位置）にジョーカーを1枚置けます。1ゲームに1回きりで、置いたら戻せません。
  • ジョーカーを置いた位置の本物のカードを持っている人は、次の自分の番で必ずそのカードを出さなければなりません（その手番はパス不可）。出すとジョーカーはそのカードに置き換わります。

👑 大富豪

CPU対戦 3〜5人 ／ 2人で対面。ジョーカー1枚入りの53枚。ローカルルールは設定画面で個別にON/OFFできます。

基本ルール（常時）

  • 強さ：3 → 4 → 5 → … → 10 → J → Q → K → A → 2（最強）。ジョーカーは単騎で最強。
  • 親（最初の人）は好きなカードを出せます。以降の人は場と同じ枚数で、より強い数字だけ出せます。
  • 出し方：1枚 ／ 2枚（同じ数字）／ 3枚 ／ 4枚。
  • 出せない・出したくない時はパス。自分以外の全員がパスすると場が流れ、最後に出した人が新しい親になります。
  • 手札を先に出し切った順に順位がつきます。

階級（連戦の時）

1位＝大富豪 ／ 2位＝富豪 ／ 中間＝平民 ／ 下から2番＝貧民 ／ 最下位＝大貧民（3人戦は富豪・貧民なし、2人戦は大富豪／大貧民のみ）。

カード交換（連戦の2ゲーム目以降）

大貧民はいちばん強い2枚を大富豪へ、大富豪は好きな2枚を大貧民へ渡します（富豪⇔貧民は1枚ずつ）。次のゲームは大貧民が親から始めます。
